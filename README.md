# Veritas Acadêmico Pro — Repositório Oficial (`veritascorretoracademico`)

## Como subir para o seu GitHub em 30 segundos:
1. Extraia este arquivo `.zip` no seu computador.
2. Abra o seu repositório https://github.com/formataedigitasuporte-jpg/veritascorretoracademico
3. Clique em **Add file > Upload files**.
4. Arraste todos os arquivos e pastas extraídos (`package.json`, `vercel.json`, `supabase_schema.sql`, pasta `api/` e pasta `public/`) e clique em **Commit changes**.
